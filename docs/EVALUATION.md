# Evaluation
`evaluation/dataset.json` has 34 synthetic policy, order, ticket, risk, escalation, injection, and confirmation scenarios. Run `python evaluation/run_evaluation.py`; it regenerates `results.json` with intent accuracy, escalation accuracy, confirmation compliance, injection refusal, and latency. Integration tests separately validate retrieval citations, isolation, tools, confirmation, and takeover. These are transparent local demonstration results—not production performance. Real deployment needs blind holdouts, human grading, adversarial breadth, load tests, and continuous monitoring.
