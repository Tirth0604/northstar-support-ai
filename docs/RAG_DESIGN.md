# RAG Design
Admin upload accepts PDF, DOCX, TXT, and Markdown. Validation applies allowlists, size checks, safe filenames, SHA-256 duplicate prevention, extraction, cleaning, page-aware chunking, embedding, and atomic vector updates. Retrieval applies metadata filtering, top-k, similarity threshold, deduplication, and bounded context. Answers require minimum evidence and expose title/page/excerpt/relevance citations. Documents are untrusted evidence, never executable instructions. Hash embeddings enable offline use; production should use evaluated semantic embeddings plus pgvector/Qdrant and reranking.
